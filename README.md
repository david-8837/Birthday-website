🎂 Happy Birthday – Premium Interactive Web Experience
​An enchanting, single-file interactive birthday experience built with vanilla web technologies, tailored animations, synthesized audio, and tactile micro-interactions.
​✨ Features Overview
​Zero Build Setup / Single File: Runs entirely in any browser out of the box with zero npm dependencies or build tools required.
​8-Stage Storybook Journey:
​Welcome Screen: Floating pixel creature with magnetic button physics and playful squeak interactions.
​Wax-Sealed Envelope: 3D envelope with animated seal cracking, opening flap, and inner light glow.
​Interactive Cake & Candles: SVG three-tiered cake with igniteable candle flames, smoke puffs, and a cutting animation.
​Music Box & Letter: Built-in audio player powered by the Web Audio API (synthesizes the "Happy Birthday" melody without external audio files) accompanied by animated equalizer bars and a rotating vinyl record.
​Polaroid Memory Album: Interactive photo gallery featuring 3D perspective tilt on desktop and touch-swipe gestures on mobile.
​Scratch-to-Reveal Wish Cards: Four interactive HTML5 Canvas scratch cards with metallic foil, sparkle trails, and auto-completion thresholds.
​Celebration Interlude: Sweet milestone greeting card with animated cat sprite and tailored confetti bursts.
​Heartfelt Letter & Replay: Parchment-style stationery with full-page reveal, custom signatures, and a smooth reset transition to experience everything again.
​Micro-Interactions & FX:
​Custom spring-physics cursor ring (for fine pointer/desktop devices).
​Haptic feedback (via navigator.vibrate on supported mobile devices).
​Multi-tiered confetti engine (canvas-confetti) with custom heart-shaped particle support.
​Floating ambient particles and subtle cursor-based parallax depth.
​Respects accessibility standards (prefers-reduced-motion and ARIA attributes).
